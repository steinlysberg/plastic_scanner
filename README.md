# Plastic Scanner — nRF52 DK + Custom PCB (OsloMet)

Embedded C firmware for a plastic scanner running on the Nordic nRF52 DK, interfacing with a custom PCB. Developed as part of the Hardware Programming (Maskinnær Programmering) course at OsloMet, taken in spring 2025.

The code was written throughout the course. The reports (1-5) shows the progression.
